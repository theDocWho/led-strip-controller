180ms

Drawing text and pictures along the strip

Your strip is addressable: every LED can show a different colour, which is how the moving effects work. But the controller's Bluetooth commands only offer one colour for the whole strip or one of its built-in effects. No per-LED command for MELK controllers has been published, so no app can draw letters or a picture on it yet. Image and Text modes above play over time on the whole strip for this reason.

Two ways to unlock it:

1. Capture LotusLamp X. If LotusLamp X has a screen where you colour individual LEDs or segments (often called DIY or Custom), it must have a per-LED command. Record it with Android's Bluetooth HCI snoop log (Developer options) while you use that screen, then share the log so the command can be decoded and added here.

2. Swap the controller for an ESP32 (about ₹400–600). Your strip's 3 wires (5V, Data, GND) go to the ESP32, and it can then show scrolling text, pictures and any pixel animation, still controlled from your phone.

Timer stored on the strip (works with phone off)

Sets the controller's clock from your phone, then saves the on/off times on the controller. If the controller loses power, its clock resets, so tap Save again. Experimental: this uses the timer commands of the ELK controller family and may not be supported on every model.

Sleep timer

Keep running

A web page can't run with the screen off. Schedules, the sleep timer and phone-run effects work while the page is open and connected, for example on an old phone on a charger. For automations that run with no phone, use Home Assistant or an ESP32 (ask me).
